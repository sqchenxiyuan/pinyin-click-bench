# 字击 · Pinyin Click Bench

一个**只靠可见按钮点击**完成的中文拼音输入基准游戏。目标是让人类和视觉智能体在相同关卡、相同候选顺序下比较输入质量与操作成本。纯静态 HTML / CSS / JavaScript，无运行时依赖，不需要账户、网络接口或后端。

## 立即试玩

- 在线游玩：<https://sqchenxiyuan.github.io/pinyin-click-bench/>。
- 本地运行 `npm run dev` 后访问 <http://127.0.0.1:4173/pinyin-click-bench/>（ES 模块需要通过 HTTP 提供，勿直接以 `file://` 打开）。
- 切换「热身 / 漫步 / 挑战」关卡，观察目标句子。
- **只能点屏幕上的小写 QWERTY 字母按钮**输入无声调拼音。候选字从前缀开始出现，例如点 `s` 就会显示 `shi` 对应的常见候选；可以继续输入 `shi` 缩小范围，或提前选字。每页最多五个，点「下一页」翻页；不能用实体数字键直接选字。
- 标点直接点击键盘底部的中文标点按钮。错误时点「退格」：优先从尚未提交的拼音末尾删除；拼音空时从已提交文字末尾删除。无光标跳转、选区编辑、自动纠错或整句转换。
- 与目标**完全相等**时自动结束；若已提交字符数等于目标字符数但内容不同，可点「结束并交卷」保留本次准确率，也可退格修正再交卷。按「下一关」或「重新开始」继续。

### 三关固定文本

| 关卡 | 目标 |
| --- | --- |
| 热身 / easy | `你好，世界！` |
| 漫步 / medium | `今天的天气真好，我们一起去公园。` |
| 挑战 / hard | `人工智能能读懂文字，也需要耐心与准确。` |

词库是为上述关卡人工整理的**有限单字词库**，含干扰用同音字，不是通用中文输入法。候选字由匹配的拼音前缀实时汇总、去重；完整拼音优先显示对应字。每个目标汉字均可从对应拼音的候选页到达；候选顺序、分页、文本始终固定。读音以词库对应的常用无声调拼音为准，例如「的」=`de`、「与」=`yu`、「准」=`zhun`。拼音打错、没有候选字时点退格修正。逗号、句号、感叹号、问号、顿号和分号均有可见按钮。

## 视觉智能体的正式规则

1. 允许：从页面视觉读取目标、拼音显示、候选字及计分；通过普通鼠标/触控**点击可见的按钮**选择关卡、字母、候选、翻页、标点、退格、结束、下一关、重开。
2. 不允许：使用实体键盘字符输入、粘贴、输入法、浏览器控制台、脚本注入、修改 DOM/应用状态、直接调用 JS 函数、伪造计时或改写 `localStorage`。程序虽能用脚本驱动浏览器作开发测试，正式成绩不得这样生成。
3. 单个合法点击记一次动作：字母、候选字、有效翻页、标点、有效退格，以及手动交卷。禁用按钮、无效动作不计数。切换关卡及重开不计入新回合。前缀出现候选后即可选字；可以继续输入完整拼音以缩小范围，不自动选第一项。
4. 计时从首次有效的回合操作开始；关卡切换/重开清空本轮数据。自动完成或手动交卷后停止计时与编辑。显示秒数保留一位；实际计分用毫秒。页面刷新会重开本轮。
5. 目标与已提交文字按 Unicode 字符**逐位置**比较：`准确率 = round(正确位置数 / 目标字符数 × 100)`；多余字符不可输入。满分按以下确定公式计算：`得分 = round(1000 × (正确位置数 / 目标字符数)² / (1 + 用时秒数 / 30 + max(0, 点击次数 − 目标字符数) / 目标字符数 × 0.025))`。即准确性优先，时间和多余操作均有成本；开始输入前会显示实时预览得分，交卷后定格。相同分数不覆盖已有记录。
6. 本地最高分按关卡存于当前浏览器的 `localStorage`，仅供个人参考，不是可核验的远程排行榜。正式比较时同时报告关卡、最终目标/输入、准确率、用时、点击次数和得分；跨关卡分数不直接混排。

## 开发与部署

需要 Node.js 18+；**无需 `npm install`**。

```sh
npm test       # node:test 测试词库可达性、IME、计分、静态构建与预览
npm run build  # 生成 dist/，可部署到任意静态托管
npm run dev    # 本地预览，默认 127.0.0.1:4173
```

GitHub Pages 项目仓库名为 `pinyin-click-bench` 时：在仓库 Settings → Pages 中将来源设为 `Deploy from a branch`，选择 `main` / `(root)`（若使用其他默认分支则选该分支）。访问 `https://<username>.github.io/pinyin-click-bench/`。`index.html` 中的资源引用全部以 `./` 开头，故在项目子路径下正确加载；仓库根目录本身就是完整静态站点。也可以将 `dist/` **内容**作为其他静态托管的发布根目录。不要把 GitHub Pages 的 `/pinyin-click-bench/` 当作绝对根路径写进资源地址。

## 文件

- `src/ime.js`：确定性关卡/词库、状态转换、候选分页和计分，无 DOM 依赖。
- `src/app.js`：页面渲染、按钮交互、本地记录和实时计时。
- `src/style.css`：响应式暖色复古界面；仅系统字体，无外部字体请求。
- `tests/*.test.js`：Node 内置测试，覆盖三关完整输入路径、编辑、分页、计分与静态预览。
- `scripts/build.mjs` / `scripts/serve.mjs`：零依赖构建和本地预览。
